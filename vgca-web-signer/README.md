# VGCA Web-Direct Remote Signer Module

Thư mục này chứa mã nguồn **độc lập** của ứng dụng Ký số Ban Cơ yếu Chính phủ (VGCA) chạy trực tiếp trên nền tảng Web:

- **Mục tiêu:** Thay thế hoàn toàn phần mềm `Virtual CSP v2.0` và `EduSign Agent` trên máy tính.
- **Tiêu chuẩn:** Tuân thủ chuẩn quốc tế **ETSI TS 119 432 v2.0**, quy định kỹ thuật **Thông tư 185/2019/TT-BQP** và quy định văn thư điện tử **Nghị định 30/2020/NĐ-CP**.
